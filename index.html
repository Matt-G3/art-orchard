How Art Orchard Works

Every artwork is stored in a browser database. The first piece is the base art. Use Collaborate on any artwork to branch out and create a child piece.

Rules: Max branch length: 5 Same person cannot contribute twice in one branch Unlimited children (only a few displayed at once)
